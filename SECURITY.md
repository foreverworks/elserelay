# Security policy

Report a weakness privately, through GitHub's private vulnerability reporting on
this repository (Security, then Report a vulnerability), not in a public issue or
pull request. Say which commit you tested, how to reproduce it, and what an
attacker would need first and could do with it. Test only with sessions and
accounts of your own.

In scope: anything that lets a container speak for another, a message past the
rules or the limits, a held message delivered without its answer, text that shows a
person one thing and delivers another, or a token in a log. Not in scope: what a
process of an agent's own user can do to that agent.
